# Saule · новогодняя игра (боевой проект)

Карта из 5 точек с мини-играми. В каждой коробке свой QR-код: он срабатывает один раз. Прогресс хранится на сервере, без регистрации.

## Как устроено
- `server/server.js` — сервер без внешних зависимостей (Node 22+, встроенная SQLite). Отдаёт игру и API.
- `public/index.html` — игра для покупателя: карта, 5 точек, мини-игры, ручной ввод кода, код игрока для другого устройства.
- `public/admin.html` — дашборд: статистика, поиск кода и игрока, открыть точку вручную (с причиной), объединить двух игроков, журнал действий.
- `tools/gen-codes.js` — генерация уникальных кодов в базу + файлы для печати.
- `tools/backup.js` — копия базы (хранит 14 последних).
- `test/smoke.js`, `test/e2e.js` — проверки.

## Правила кодов
- Формат `SL-XXXX-XXXX`, без похожих символов (0/O, 1/I/L). Вводить можно в любом регистре и с пробелами.
- QR ведёт на `https://<домен>/?c=SL-XXXX-XXXX`.
- Код привязывается к первому игроку, который его ввёл. Второй раз он ничего не даёт, чужому игроку отвечает «уже использован».
- Одновременный скан одного кода двумя людьми засчитывается только одному (проверено тестом).
- Если у игрока уже 5 точек, новый код не тратится.

## Прогресс без регистрации
- При первом заходе браузер получает секретный ключ игрока и короткий код игрока (например `ЁЛКА-4820-MTV`).
- На другом телефоне: ссылка «отправить себе» (WhatsApp/Telegram) или ввод кода игрока.
- Если всё потеряно: поддержка находит игрока в дашборде и открывает точку вручную или объединяет игроков.

## Запуск локально
```
npm install
ADMIN_TOKEN=secret npm start         # http://localhost:8787 , дашборд /admin.html
npm test                             # проверка API
```

## Коды для печати (1000 штук + запас)
```
node tools/gen-codes.js --count 1000 --reserve 50 --base https://saule.shustudio.kz --batch print-1
```
Результат в `out/print-1/`: `codes.csv` (для типографии, печать переменных данных), `qr/*.svg` (векторные QR), `sheet.html` (лист для пробной печати).
Генерировать **один раз на боевом сервере** (коды должны попасть в боевую базу). Домен в QR после печати менять нельзя.

## Установка на сервер (Ubuntu, как у catalog.shustudio.kz)
1. Скопировать папку в `/opt/saule-game`, `npm install --omit=dev`.
2. `.env` по образцу `.env.example` (длинный ADMIN_TOKEN).
3. `deploy/saule-game.service` → `/etc/systemd/system/`, `systemctl enable --now saule-game`.
4. `deploy/nginx-saule.conf` → nginx, `nginx -t`, перезапуск, `certbot --nginx -d saule.shustudio.kz`.
5. `deploy/backup.cron` → `/etc/cron.d/saule-game`. Копировать бэкапы ещё и вне сервера.
6. Мониторинг: внешний сервис проверяет `https://saule.shustudio.kz/api/health` каждые 5 минут.
7. Сгенерировать коды (см. выше), отдать `codes.csv` и `qr/` в типографию, сделать пробную печать 10 штук и отсканировать.
